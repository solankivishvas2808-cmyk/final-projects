## 🎯 Project Objective

The main objective of this project is to perform **Exploratory Data Analysis (EDA)** on the Titanic dataset and identify the major factors associated with passenger survival.

The analysis focuses on variables such as:

- Passenger Class
- Gender
- Age
- Fare
- Family Size
- Embarkation Port
- Survival Status

The project uses visualizations to make the analysis easy to understand and to identify meaningful patterns within the dataset.

---

## 📊 Analysis Performed

### 1. Dataset Overview
- Loaded the Titanic dataset using Pandas
- Examined rows and columns
- Reviewed dataset structure
- Checked data types
- Identified missing values

### 2. Data Cleaning
- Handled missing values
- Prepared numerical and categorical variables
- Created additional features such as age groups and family size

### 3. Survival Analysis
Analyzed the overall survival rate and compared survival outcomes across different passenger groups.

### 4. Survival by Gender
Compared survival rates between male and female passengers.

### 5. Survival by Passenger Class
Analyzed survival rates for:
- First Class
- Second Class
- Third Class

### 6. Survival by Class and Gender
Combined passenger class and gender to understand how these factors were associated with survival.

### 7. Age Analysis
- Studied age distribution
- Compared age with survival
- Created age groups
- Visualized survival rates across age groups

### 8. Fare Analysis
Examined the relationship between passenger fare and survival outcomes.

### 9. Embarkation Analysis
Analyzed survival rates according to the passenger's port of embarkation.

### 10. Family Size Analysis
Created a family-size feature using siblings/spouses and parents/children information and examined its relationship with survival.

### 11. Correlation Analysis
Used a correlation heatmap to understand relationships among numerical variables.
