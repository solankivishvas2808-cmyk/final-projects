## 📌 Project Overview

**Air Quality Analysis & Visualization** is a data analysis project developed using **Python, Pandas, NumPy, Matplotlib, and Seaborn**.

The project analyzes an air-quality dataset containing pollutant measurements and environmental parameters. It focuses on cleaning the dataset, performing statistical analysis, identifying pollution patterns, studying relationships between variables, and presenting the results through meaningful visualizations.

The complete analysis is implemented in a **Jupyter Notebook** and uses the `AirQualityUCI.csv` dataset.

## 📊 Analysis Performed

### 1️⃣ Dataset Information
The project begins by examining the dataset structure, shape, columns, and available information.

### 2️⃣ Data Cleaning
Invalid values such as `-200` are treated as missing values and converted into `NaN` so that the analysis can be performed more reliably.

### 3️⃣ Statistical Summary
Descriptive statistics are calculated to understand the distribution and general behavior of the air-quality measurements.

### 4️⃣ Average Pollution Levels
Average values of major pollution-related variables are analyzed to understand the overall pollution condition represented by the dataset.

### 5️⃣ CO Concentration Over Time
A time-series visualization is used to observe how **Carbon Monoxide (CO)** concentration changes over time.

### 6️⃣ NO₂ Concentration Over Time
The project studies the variation of **Nitrogen Dioxide (NO₂)** concentration over time.

### 7️⃣ Pollution Distribution
Distribution analysis helps understand how frequently different pollutant concentration levels occur.

### 8️⃣ Temperature vs NO₂
The relationship between **temperature** and **NO₂ concentration** is explored using visualization and statistical analysis.

### 9️⃣ Correlation Heatmap
A correlation heatmap is used to identify relationships between different numerical air-quality variables.

### 🔟 Monthly Pollution Analysis
Pollution measurements are grouped and analyzed on a monthly basis to identify possible seasonal patterns.

### 1️⃣1️⃣ Maximum & Minimum Pollution
The analysis identifies important maximum and minimum values for pollution-related variables.

### 1️⃣2️⃣ Correlation Analysis
Correlation values are examined to understand which variables have stronger or weaker relationships with each other.

## 🚀 How to Run the Project

### Step 1 — Install Python

Make sure Python is installed on your computer.

### Step 2 — Install Required Libraries

Open Terminal / Command Prompt and run:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 3 — Keep the Files Together

Make sure these files are inside the same project folder:

```text
Air_Quality_Analysis_Final.ipynb
AirQualityUCI.csv
```

### Step 4 — Open Jupyter Notebook

Run:

```bash
jupyter notebook
```

Then open:

```text
Air_Quality_Analysis_Final.ipynb
```

### Step 5 — Run the Notebook

Run the notebook cells from top to bottom.

> ⚠️ **Important:** Keep `AirQualityUCI.csv` in the same folder as the notebook so that the dataset can be loaded correctly.
