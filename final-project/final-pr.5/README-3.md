## 📌 Project Overview

This project presents a structured analysis of stock-market data using
**Python, Pandas, Matplotlib and Seaborn**.\
The objective is to transform raw CSV data into meaningful insights
through data cleaning, sector-wise analysis, performance analysis and
visualizations.

The project is developed in a **Jupyter Notebook (`.ipynb`)** and
focuses on presenting financial data in a clear, simple and professional
manner.

------------------------------------------------------------------------

## 🎯 Objectives

-   Analyze stock-market data from a CSV dataset.
-   Clean and prepare the data for analysis.
-   Understand sector-wise stock distribution.
-   Analyze average percentage changes across sectors.
-   Identify variations in stock performance.
-   Present findings using clear and effective charts.
-   Generate meaningful **Key Insights** from the dataset.

## 📊 Analysis Performed

### 1. Data Loading & Preparation

The CSV dataset is loaded into Python and prepared for further analysis.

### 2. Data Cleaning

Relevant columns and missing values are handled to make the dataset
suitable for analysis.

### 3. Sector-Wise Analysis

The project examines the distribution of listed shares across different
sectors.

### 4. Performance Analysis

Average percentage change is calculated to understand sector-level
market performance.

### 5. Visualization

Charts are used to make comparisons and trends easier to understand.

## 💡 Key Insights

    volatility**.
-   Some sectors have **higher average percentage changes** than others.

## 🚀 How to Run the Project

1.  Install Python and Jupyter Notebook.
2.  Keep the `.ipynb` file and CSV dataset in the same folder.
3.  Open the notebook in Jupyter Notebook or VS Code.
4.  Make sure the required Python libraries are installed.
5.  Run the notebook using **Run All**.
6.  Review the generated tables, charts and key insights.

### Required Libraries

``` bash
pip install pandas matplotlib seaborn jupyter
```
